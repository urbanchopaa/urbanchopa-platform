# urbanchopa-platform
Urban Chopa is an on-demand delivery and commerce platform connecting users with local vendors.

## Project Goal

This repository contains the implementation of Urban Chopa's Stellar-powered settlement infrastructure, enabling efficient settlement between customers, vendors, and platform operators.
